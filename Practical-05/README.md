# Practical 05 - API and CSV Data Extraction

## Objective
Extract data from an external API and local CSV, merge records, and save cleaned output.

## Contents
- `data_extraction.py`
- `locations.csv`
- `cleaned_warehouse_profiles.csv`
- Supporting screenshots of script execution/output

## Prerequisites
- Python 3.10+
- `pandas`
- `requests`
- Internet connectivity for the API call

## Dependency install
```bash
pip install pandas requests
```

## Execution
```bash
cd Practical-05
python data_extraction.py
```

## Learning outcomes
- Practice extraction from REST API and CSV sources.
- Merge the sources into a cleaned analytical output.
