# Practical 08 - PySpark CSV Processing

## Objective
Process sales and product CSV files using PySpark DataFrame operations including filtering, aggregation, deduplication, and joins.

## Contents
- `pyspark_csv_operations.py`
- `sales.csv`
- `products.csv`

## Prerequisites
- Python 3.10+
- Java runtime
- Apache Spark / PySpark

## Execution guidance
```bash
cd Practical-08
python pyspark_csv_operations.py sales.csv products.csv
```

## Learning outcomes
- Apply Spark DataFrame transformations and aggregations to CSV data.
