# Practical 02 - Power BI Retail Dashboard

## Objective
Build a business-intelligence dashboard from a retail sales dataset using Power BI.

## Contents
- `business intelligence practical.pbix`
- `Meridian_Retail_Sales_Dataset.xlsx`
- Dashboard screenshots:
  - `Sales_Overview.png.png`
  - `Sales_Channel_Performance.png.png`
  - `Product_Analysis.png.png`
  - `Forecast_Summary.png.png`

## Prerequisites
- Microsoft Power BI Desktop
- Spreadsheet viewer (Excel-compatible)

## Usage guidance
1. Open `business intelligence practical.pbix` in Power BI Desktop.
2. Verify source links to `Meridian_Retail_Sales_Dataset.xlsx` if prompted.
3. Compare pages with repository screenshots.

## Expected/available outputs
- Interactive Power BI report and static screenshot exports.

## Troubleshooting
- If data source is broken, rebind the Excel file path in Power BI.
- Ensure locale/date settings are consistent with the dataset format.
